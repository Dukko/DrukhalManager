# Getting Started

## 1. Open the app

DrukhalManager finds Stellaris in your Steam libraries and reads the mods you've subscribed to or installed locally. The **Load Order** page lists them: the enabled ones in the order the game loads them, and the disabled ones below.

If Steam or a library lives on another drive and you use the Flatpak, the app shows the command that gives it access.

## 2. Arrange your load order

Turn mods on and off with the switch on each row, and drag them into order. The quickest way to a sensible order is **Smart Sort**, which previews the order before moving anything. See [[Load Order and Smart Sort]].

## 3. Save

Press **Save** (Ctrl+S). That writes the load order for the game and the Paradox Launcher. **Launch** also saves before starting the game.

## 4. Add a Steam Web API key (optional, recommended)

Some features need your own Steam Web API key:

* Reading the **Required items** a mod lists on its Workshop page, so the app can warn you when one is missing.
* [[Finding Compatibility Patches]].

Get a key at [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey), then paste it in **Main Menu → Preferences → Steam**. It's kept in your system keyring, or, without one, in a settings file only your user can read.

## 5. Launch

Press **Launch**. Its dropdown has other ways to start the game; see [[Launching and Saves]].
