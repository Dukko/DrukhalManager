# DrukhalManager

DrukhalManager is a Stellaris mod manager for Linux. It manages load orders and collections, shows which mods overwrite each other, and can merge conflicting mods with AI into a patch that loads last.

These pages explain how to do things in the app, one task at a time. To install it, see [Installing](https://github.com/Dukko/DrukhalManager#installing) in the README.
