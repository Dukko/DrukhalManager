# Where Things Are

## The window

* **Header, left:** the collection picker, then **Undo**, **Redo** and **Reload Mods**.
* **Header, middle:** the **Load Order** and **Conflicts** pages (Alt+1, Alt+2).
* **Header, right:** **Save**, **Launch** and its dropdown, the notifications bell, and the main menu (☰).
* **Health strip:** above the list, cards counting what needs a look, each with what to do about it.
* **Sidebar:** views (Needs Attention, Not Updated, Has Conflicts…), the Smart Sort categories, and at the bottom, facts about your game and last save.
* **Inspector:** on the right, details for the mod you click.

## What moved out of the main menu

The main menu now holds only what's about the app itself: **Preferences**, **Keyboard Shortcuts**, **Troubleshooting** and **About**. Everything else sits next to what it acts on.

| It used to be in the main menu | Now it's |
| --- | --- |
| Undo, Redo | Arrow buttons at the top left (Ctrl+Z, Ctrl+Shift+Z) |
| Reload Mods | The refresh button at the top left (F5) |
| Saves… | Launch dropdown |
| Multiplayer Check… | Launch dropdown |
| DLC… | Launch dropdown |
| Find the Crashing Mod… | Launch dropdown |
| Mods Not Updated for This Game… | **Disable for Now…** on the "not updated" card in the health strip |
| Find Compatibility Patches… | **Find More…** on the Compatibility Patches header in the list, or at the foot of the sidebar's categories while you have no patches |
| Last Game's Errors… | "Last game logged N errors" at the bottom of the sidebar, shown when there were errors |
| Merged Patch Backups… | The backups button at the bottom of the Conflicts list, beside **Rules…** and **Rescan** |

Keyboard shortcuts haven't changed. Press **?** to see them all.
